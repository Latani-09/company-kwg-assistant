# Resources

This folder is reserved for product, design, and research assets that support the Company Knowledge Assistant project.

## Recommended structure

- `prototypes/` — HTML prototype files, design mockups, and interactive trial versions
- `docs/` — product briefs, decision logs, architecture notes, and planning documents

## Use this folder for

- static mockups and prototype screens
- UX research notes
- stakeholder documentation
- technical decision records
- screenshots or exported design files
- any supporting materials that are not part of the application code

## Naming guidance

Use descriptive filenames and keep dated or versioned documents easy to track, for example:

- `prototype-v1.html`
- `dashboard-wireframe.html`
- `technical-decisions.md`
- `user-flow-notes.md`
